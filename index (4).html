01About

From the cable to the database.

Every click travels a long way: out of a screen, through a switch and a router, into an API, down to a row in a database, and all the way back. I like working on every stop along that path, so I'm equally happy in a Cisco lab, a code editor or a SQL console.

screenReact · Angular
networkVLANs · Cisco
APIDjango · Node.js
dataMySQL · SQL

I build REST APIs with JWT auth, design the tables behind them, and wire them to interfaces people actually enjoy using. I've also kept real offices running as first-line support at the National Social Security Fund and Revere Technologies. When something breaks I fix it, then write down what happened so the next fix is faster.

Based in Nairobi. BSc Information Technology, Maseno University.
